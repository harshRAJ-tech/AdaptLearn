Project Background

Problem Statement & Objective

Traditional static course-listing websites present the same content and assessment difficulty to every learner, regardless of their individual performance. There is no simple client-side mechanism that adjusts question difficulty based on real-time performance.

This project addresses that gap by building a lightweight, rule-based adaptive assessment flow along with a visual instructor dashboard, using straightforward local scoring rules without depending on external infrastructure.

Scoring Transition Rules
1. Correct Answer: Promotes difficulty: Easy $\rightarrow$ Medium $\rightarrow$ Hard (stays at Hard on streak).
2. Incorrect Answer: Drops difficulty: Hard $\rightarrow$ Medium $\rightarrow$ Easy (stays at Easy for reinforcement).
3. Audit Trail: Stores complete difficulty path and performance metrics locally.
